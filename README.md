# Ahyan Aslam – Portfolio

Static portfolio website (HTML, CSS and vanilla JavaScript). No build step or dependencies.

## Structure
- `index.html` – page content
- `css/style.css` – styles
- `js/main.js` – project slideshows, hover previews, scroll effects, theme toggle
- `assets/` – profile cutout and project images

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then save.

## Edit
- Project text and images: the `P` array at the top of `js/main.js`.
- Contact email: `EMAIL` in `js/main.js` and the links in `index.html`.
